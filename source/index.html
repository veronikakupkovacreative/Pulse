Edit audio without installing apps, creating accounts, or leaving the tab. Pulse Studio brings common audio edits into one focused workspace: open compatible audio formats, make changes in browser memory, then export as MP3, 16-bit PCM WAV, M4A/AAC at 192 kbps where supported, or FLAC.

    ( CHOOSING )

    Choose an MP3 bitrate for the job.

    More bitrate = larger files. It cannot restore lost source quality.

    BITRATE

    64 kbps

    PRACTICAL STARTING POINT

    Speech drafts and very compact spoken-word files.

    TRADEOFF TO CHECK

    Music and ambience can show obvious compression artifacts.

    BITRATE

    96 kbps

    PRACTICAL STARTING POINT

    Compact speech when download size matters.

    TRADEOFF TO CHECK

    Sibilance and complex backgrounds deserve a careful preview.

    BITRATE

    128 kbps

    PRACTICAL STARTING POINT

    Balanced general-purpose MP3 and spoken content.

    TRADEOFF TO CHECK

    Dense music can benefit from a higher setting.

    BITRATE

    192 kbps

    PRACTICAL STARTING POINT

    Music or mixed content with more quality margin.

    TRADEOFF TO CHECK

    Produces a larger file than 128 kbps.

    BITRATE

    256–320 kbps

    PRACTICAL STARTING POINT

    High-bitrate delivery when file size is less important.

    TRADEOFF TO CHECK

    Cannot restore detail already lost in the source.
